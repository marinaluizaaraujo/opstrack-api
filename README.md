# OpsTrack API

API simples de acompanhamento de status e chamados.

## Rotas disponíveis

| Rota      | Método | Descrição                              |
|-----------|--------|------------------------------------------|
| `/status` | GET    | Retorna o status do serviço              |
| `/tickets`| GET    | Retorna uma lista mockada de chamados    |
| `/sobre`  | GET    | Retorna informações básicas da API       |

## Como rodar

\`\`\`bash
pip install flask
python app.py
\`\`\`
